# 幻方世界 · Blocklands

**作者：Feng Zhangyu**

一个使用 Unity 制作的第一人称方块沙盒冒险游戏。建造房屋、探索矿层、
驾驶飞行房车、经营自己的秘密基地，也可以邀请朋友参加派对。

当前源码版本：**2.27**。主要开发与验证平台：macOS。

![幻方世界概念主视觉](Assets/Resources/LoadingWorldKeyArt.png)

上图为 AI 生成的概念插画，不是实机画质。游戏内场景由项目代码实时生成。

## 可以玩什么

- **探索世界**：林地小屋、风铃村庄、水晶矿谷、粉晶城堡、梦影地、熔岩竹谷及其他旅行地区。
- **采集与合成**：九宫格工作台、配方本、多种工具、装备和可放置方块。
- **建造与生活**：房屋、家具、电视、书籍、钱包、商店、密码保险箱和储物柜。
- **秘密基地**：九层地下空间、升降椅、实时游戏监控与无人机。
- **房车旅行**：八座汽车、飞行、乘客、行李、房车床铺与洗漱设施。
- **朋友与派对**：邀请函、手机文字对话、舞台、彩灯、音响、秋千和滑梯。
- **冒险挑战**：梦影龙、村民追赶、海啸及医护救援等游戏化事件。
- **启动加载画面**：专属主视觉、实际初始化阶段进度及轮播玩法提示。

这是持续迭代的原创项目，不是其他商业游戏的官方版本。

## 打开项目

1. 安装 Unity Hub 和 **Unity 6000.6.0f1**。
2. 克隆本仓库，在 Unity Hub 中添加仓库根目录。
3. 等待 Unity 导入资源。
4. 打开 `Assets/Scenes/Blocklands.unity`，点击 Play。

运行入口通过 `Sandbox.Boot` 自动创建世界。无需外部服务器、API 密钥或账号。
首次导入 Unity 包和安装编辑器可能需要联网；游戏玩法本身不依赖远程服务。

## 基本操作

| 输入 | 用途 |
| --- | --- |
| W/S、方向键 | 移动；在车辆等模式中控制对应对象 |
| 鼠标 | 环顾、瞄准、选择物品 |
| 空格 | 跳跃；部分场景中抓扶杆或执行提示动作 |
| E | 背包与九宫格合成 |
| T | 旅行地图 |
| Esc | 暂停、返回或关闭当前界面 |
| 左键 / 右键 | 采集或攻击 / 放置；具体取决于手持物品 |
| R | 使用手中的食物 |
| H | 场景交互；注意屏幕上的短按/长按提示 |
| A | 游戏中的手机 |
| G | 附近的游乐或生活活动 |
| 字母 O | 召车、走近后上车；有请求时同意上客 |
| 数字 0 | 在驾驶位起飞或开始降落 |
| 数字 7 | 在驾驶位切换房车 |
| 车内空格 / Shift | 飞车升高 / 下降 |

按键随场景变化，请以界面提示为准。启动后点“开始探索”才进入游玩。

## macOS 语音组件（可选）

手机可以使用文字输入，无需麦克风权限。若需要本机中文语音识别，
安装 Xcode Command Line Tools，然后在仓库根目录运行：

```sh
zsh Native/build.zsh
```

该命令从本仓库源码构建本机插件，不下载预编译程序。
首次使用语音按钮时，需要允许麦克风与语音识别权限，
并安装系统支持的本机中文识别资源。不支持时可以继续打字。

公开源码未包含4段预生成 NPC 语音；缺少这些语音时，相应文字和字幕仍可用。
这不影响建造、探索和其他主要玩法。详见[第三方说明](THIRD_PARTY_NOTICES.md)。

## 构建 macOS 应用

安装 Unity 的 macOS Build Support。编辑器菜单选择
**Blocklands → Build macOS game**。

也可以把 `UNITY_EDITOR` 设置为本机 Unity 可执行文件路径，再运行：

```sh
"$UNITY_EDITOR" -batchmode -quit \
  -projectPath "$PWD" \
  -executeMethod ProjectTools.BuildMac \
  -logFile ./build.log
```

产物为 `Builds/Blocklands.app`。构建过程会运行项目检查并进行本机临时签名。
这不是 Apple 公证的发布包；对外分发安装包需要自行处理正式签名与公证。
本仓库只提供源码与必要资源，不含游戏乐园启动器或编译应用。

## 测试与存档隔离

编辑器菜单 **Blocklands → Run world checks** 检查体素、物理、配方及保存数据。
游戏还有显式启用的运行时回归检查，例如：

```sh
./Builds/Blocklands.app/Contents/MacOS/幻方世界 \
  -blocklands-smoke "$PWD/Verification/local-loading-check" \
  -loading-screen-only \
  -logFile "$PWD/Verification/local-loading-check.log"
```

`-blocklands-smoke` 后必须指定独立测试目录。不要用真实玩家存档目录做测试。
加载画面检查在可见窗口中可产出截图；Unity 批处理模式的部分截图 API 不可用。
`Verification/` 只保存在本地，不提交到仓库。

本次源码发布前，加载与存档、九层基地、合成页面共96项不同运行时检查通过，
并验证了1440×900和960×640窗口。它不表示整个游戏已无 bug。

Unity 编辑器和操作系统自身的数据处理受其各自设置与条款约束。

本仓库不包含：玩家存档、真实录音、聊天记录、个人邮箱、Unity 缓存、
本机日志、测试输出、生成的应用包或来源授权未明确的预生成语音。
